# Commit guidelines

Do not use Conventional Commit prefixes or scopes in this repository. Otherwise, follow commit best practices: use a
concise imperative subject, explain non-obvious reasoning in the body, and reference the relevant work item.

Create a new commit for later edits or changes in direction so the history preserves how the work evolved. Amend only
when the new change genuinely belongs to the previous commit and that commit has not been pushed to a remote.
