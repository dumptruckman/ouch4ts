# Triage labels

Map each canonical role to its label in GitHub Issues.

| Role | Label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue |
| needs-info | needs-info | Waiting for more information from the reporter |
| ready-for-agent | ready-for-agent | Fully specified and ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be implemented |

When a skill names a triage role, use the corresponding label.
Edit the Label column to change the vocabulary.
